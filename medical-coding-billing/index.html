Medical Coding & Billing

Coders read the chart and assign the diagnosis, procedure, and modifier the documentation supports. Billing then turns that into a claim the payer can adjudicate, with the edits caught before submission.

Desk Overview

How the work is run

  • Codes come from the chart, not from a guessed superbill
  • Modifiers, units, and place of service checked before the claim leaves
  • A weekly audit sample, with the misses sent back to the coder
  • The same encounter can move into AR calling without being re-keyed
The Operating Problem

A claim is only as clean as the code behind it

Denied and underpaid claims often start with a code the note does not support, a missing modifier, or a charge that never left the encounter form. The desk keeps coding and billing on one encounter so the claim matches the visit.

Scope & Deliverables

What this desk takes on

The work is a queue with an owner, a note, and a next action. These are the pieces that queue contains.

Specialty coding from the record

Evaluation and management, surgery, radiology, lab, and anesthesia, coded to the note that was signed.

  • ICD-10-CM diagnoses tied to the documented condition
  • CPT and HCPCS with the modifier the payer expects
  • A query back to the provider when the note is thin

Charge capture before the claim

The encounter becomes a charge only when the documentation and the code agree.

  • Units and place of service taken from the visit
  • Duplicate charges held instead of billed twice
  • A same-day charge lag so visits do not sit unbilled

Claim scrub and payer edits

Edits run before the file goes out, not after the denial comes back.

  • Gender, age, and diagnosis-pointer checks
  • Payer-specific rules for the plans you bill most
  • A clean-claim count you can read each week

Professional and facility billing

The same visit can need a professional claim and a facility claim, kept distinct.

  • CMS-1500 and UB-04 paths kept separate
  • Referring and rendering providers named correctly
  • A hold when an authorization number is missing

Coder review and feedback

A sample of charts is re-read so a pattern is caught before it becomes a quarter of denials.

  • A scored sample each week
  • Misses grouped by coder and by specialty
  • The correction written back onto the rule, not only the claim

A handoff the next desk can use

Coding, billing, and AR share one encounter instead of three spreadsheets.

  • The code, the claim number, and the note stay together
  • A denial can be traced to the code that caused it
  • Hospital software can feed the encounter when you already run one

Methodology

How a day on this desk runs

Four steps, kept visible, so a claim does not sit between two people.

Chart intake

The signed note, the orders, and the encounter form land in one queue, with incomplete charts held.

Code assignment

Diagnosis, procedure, and modifier are assigned to the documentation, and a query goes back when the note is not enough.

Scrub and submit

Payer edits run, the claim is released, and the exceptions stay on a worklist with an owner.

Audit and handoff

A sample is re-coded, and accepted claims move to payment posting and AR with the encounter still attached.
